# human-led

人間がコンセプトとルールを決め、AIに実装させたローグライク風スネーク（ログスネ）。

## ドキュメントの地図

| 知りたいこと | 場所 |
|---|---|
| ゲームのルール | `docs/concept.md` |
| 決めたことと、その理由 | `docs/discussions/` |
| 言葉の意味 | `GLOSSARY.md` |
| コードの全体像、構成とつながり、実装とアルゴリズム | `docs/internals/` |
| 開発の始め方とコマンド | `README.md` |

## 決まり

- コードを変えるときは、関係するドキュメント（ルール、内部の挙動、用語）も同じPRで直す
