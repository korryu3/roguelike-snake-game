# ローグライク風スネークゲーム 検討事項

- memo
- ステージは、m分の間にn個のリンゴを食べたら、完了
  - ステージクリア時間が短ければ短いほどポイントが上がる
    - 取得したリンゴの数*p + 制限時間の短さ/pで加算する
  - 完了したら強化画面に移る
    - 取得したポイントで強化が買える

3〜9がゲームのルールの骨格。ここが変わると、状態の持ち方とロジックを作り直すことになる。

### メモ：強化項目

### 絶対に作る強化項目

- ポイント2倍、長さ2倍（数値は変動？）
- 死んでも1回生き返る（高額ポイント）
- 死んでも一回生き返るが、{デメリット（例：生き返ってs秒は遅いなど）}。
  - デメリット付きはちょっとポイント安め
- タイマーを5秒延長する（恒久的に）
- 次のステージだけ、時間制限を伸ばす（一時的）
- 壁に当たってもダメージを受けない（1度だけ / 開始数秒だけなど）。
  - ただ、自分分の体に当たったらダメージは受ける。
- ライフの上限+1（上がり幅は上限設ける）
- n%の確率で2倍ポイントのリンゴが出る

#### できたら作る強化項目

- ステージクリアのための必要リンゴ数アップ。
  - メリット：リンゴが増えるとポイントup. デメリット：クリアむずい/時間かかる
- 体の一部を切り落とす（例：強化で選ぶ -> 次のステージで自分の体のぶつかったところを切断（使い切り））
- n%の確率で選択肢が増える（4つになるなど）
- スネークの動くスピード1.5倍
- スピードが落ちるけどポイント倍率が少し上がる

### メモ: 遊ぶのが先生だけであることから言えること

- 遊ばれるのは採点や発表のときの数分だけの見込み。1回のプレイは数分で一通り遊べる長さにする（#4）
- 説明なしで遊べるようにする。最初の画面で操作方法が分かること
- 見られるのは見た目のインパクトより、コンセプトが練られているか。ルールの骨格（3〜9）がかみ合っていることを優先する
- コンセプトの説明は発表スライドに任せる。ゲームは説明に頼らず、作品として完成させる

### 実装しながら決めること

遊んでみないと決められない調整と、UXに関すること。

- 盤面のマス数（例: 20×20。狭いと序盤から窮屈になり、広いと間延びする）
- 移動速度や曲がるときの反応などの数値
- エフェクトや画面の揺れの強さ
- 難易度曲線とバランスの数値、壊れビルドをどこまで許すか
- 死んでから再挑戦するまでの手間（1キーですぐ再挑戦できるか）
- 死因の分かりやすさ（理不尽ではなく「もう1回」になるか）
- チュートリアル（最初のステージに組み込むのが軽い）
- 一時停止、別タブに移ったときの自動停止、中断したプレイの再開
- 強化や敵の説明の見せ方
- アクセシビリティ（色だけに頼らない、矢印キーとWASD、速度を遅くするオプション）
