# 設定メニューと一時停止（2026-11-07）

**状態: 決定**

音を消すボタンが見つけにくかったことから、一時停止と音量の調整をまとめた設定メニューを作ることにした記録。前日に「ポーズ機能は作らない」と決めていたが、音量を変える場所として役割ができたので覆した。

## 決めたこと

### Q1. 開き方

- **結論**: 右上に「⏸ 設定」ボタンを1つだけ置く。どの画面でも同じメニューを開き、ステージ中に開いたときだけゲームも止まる。Escキーでも開閉できる
- **理由**: 一時停止のボタンと音の設定のボタンを分ける理由がない

### Q2. メニューの中身

- **結論**: 「再開」（ステージ以外では「閉じる」）、BGMの音量、効果音の音量（どちらも0〜100%のスライダー）
  - 効果音のスライダーは、動かし終えたら効果音を1回鳴らして聞かせる
  - 左下の音を消すボタンはなくす。音を消したいときはスライダーを0にする
  - 「タイトルへ戻る」は入れない

### Q2-2. 言語の切り替え

- **結論**: タイトルにあった日本語と英語の切り替えを、設定メニューの中に移す。ゲームの途中でも言語を変えられる
- 設定ボタンの置き場所
  - ステージ中は、時間制限の真上に「⏸ 設定」
  - タイトルは、「ゲーム開始」の下に「⚙ 設定 / Settings」。日本語を読めない人も英語への切り替えを見つけられるように、言語によらず両方の言葉で出す
  - ゲームオーバーは、ボタンの下に「⚙ 設定」
- **理由**: 設定ボタンをタイトルの右上に置くと、位置が浮いて見えた。言語の切り替えを設定に入れれば、タイトルの部品も減る

### Q3. 止めているあいだのBGM

- **結論**: 流し続け、スライダーを動かすとその場で音量が変わる

### Q4. 再開の仕方

- **結論**: メニューを閉じても止まったままにし、「方向キーで再開」を出す。方向キーを押したら、その方向へ動き出す。止めているあいだに押した方向キーは捨てる
- 真後ろ（首の方向）のキーは、ふだんと同じく無視する
- **理由**: 再開した直後にダメージを受けるのは理不尽に感じる

### Q5. 音量の保存と既定値

- **結論**: 音量はプレイヤーの設定として、ブラウザに保存する。既定値は`config.ts`の`AUDIO`にまとめ、調整パネルには出さない
- クリアとゲームオーバーのあいだは、設定した音量の5割にする
- **理由**: 音量は遊びのバランスではなく見せ方の数値で、一度合わせれば頻繁には変えない

## ライブラリを使うか

- **結論**: まだ使わない
- **理由**: 複雑になってきたのは画面の状態（メニューの開閉、止める、再開待ち）で、ライブラリを入れても減らない。音はブラウザの標準の機能で足りている。効果音が遅れる・鳴らない、音量をなめらかに変えたい、スマホでも鳴らしたい、といった問題が出たら、音だけ小さなライブラリ（Howler.jsなど）に置き換える
- 機能を足したあとに、画面まわりのコードを整理する
