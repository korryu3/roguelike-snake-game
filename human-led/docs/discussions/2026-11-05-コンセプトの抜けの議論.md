# コンセプトの抜けの議論（2026-11-05）

**状態: チームに未確認**

チームで決めたコンセプト（[roguelike-snake-検討事項.md](../roguelike-snake-検討事項.md)）を読み、抜けている観点や、ルール同士がかみ合っていない点をAIと議論した記録。ここに書いた結論は、チームと確認するまで決定ではない。

数値はすべて例で、遊んで調整する前提。

## まとめ

**集めたポイントで強化を買い、スネークを改造しながら、どこまでステージを進めるかを競う。**

## 世界観と呼び名

### Q1. ロボット・SFの世界観に合わせて、呼び名を変えるか

- **結論**: 次のように変える
  - ポイント → エネルギー（通貨）
  - 強化 → モジュール（機体に取り付ける）
  - スネーク、ハートは今のまま。ハートは機体のコア（心臓）とも読める
  - リンゴ → エネルギーセル（ほかの候補: エネルギーコア / バッテリー / プラズマ球 / 燃料ペレット）
  - この記録の本文では、チームの今の呼び名（リンゴ、ポイント、強化）を使う
- **理由**: 「集めたエネルギーでモジュールを買い、機体を改造する」という一貫した話になる。リンゴをエネルギーコアと呼ぶと、ハート（機体のコア）と「コア」が重なる

## ステージ

### Q2. ステージクリアの条件

- **選択肢**: (a) リンゴをn個食べた瞬間にクリア / (b) n個食べるとゴールが現れ、ゴールに入るとクリア / (c) 制限時間が終わるまで続き、n個以上食べていればクリア
- **結論**: (b)。ゴールに入るまでは、リンゴを追加で食べ続けられる
- **理由**: (a)だと、毎ステージ全員がn個ずつ伸びるだけになり、長さで迷う場面がない。(b)なら「もっと食べればポイントは増えるが、体が長くなり、時間ボーナスも減る」という迷いが毎ステージ生まれる

### Q3. ゴールが出たあとの決まり

- **結論**
  - リンゴは常に盤面に1個。食べると次の1個が出る
  - ゴールは、n個食べた時点でランダムな位置に現れる
  - ゴールが出たあとも制限時間は減り続ける
- **理由**: 欲張りすぎると時間切れになる、という罰が生まれる

### Q4. 時間切れになったら

- **結論**: ゲームオーバー

### Q5. 必要なリンゴの数と制限時間の関係

- **結論**: ふつうに遊んで30〜60秒ほどでゴールが出る数をnにする。制限時間はそれより長くする（例: 1分30秒〜3分）
- **理由**: 数値を調整するときの、最初の基準として置く。ステージが進んでもnは変えない前提（Q7）なので、この秒数がすべてのステージの基準になる。Q7でnをステージごとに変えることになったら、最初のステージの基準と読み替える

### Q6. 進行バーが表すもの

- **結論**: 食べたリンゴの数（n個中いくつか）。ゴールが出たら、満タンのまま光るなどして知らせる
- **理由**: 残り時間はタイマーが別に表示している

## 長さ

### Q7. ステージが進んだときの難易度の上げ方

- **結論**: 長さの持ち越しだけで難易度を上げる。必要なリンゴの数や制限時間をステージごとに変えるかは、遊んでから決める
- **理由**: 長さを持ち越すので、ステージが進むほど盤面が窮屈になり、自然に難しくなる

### Q8. 長い体のままステージを始めるときの置き方

- **結論**: ステージ開始時は頭だけで現れ、進むにつれて元の長さまで体が伸びる
- **理由**: 開始直後に、壁と体が重なる事故を防げる

## ぶつかったとき

### Q9. ぶつかったときの処理

- **結論**: HPが1減り、短い無敵時間が付く
- **理由**: 無敵時間がないと、ぶつかった次の瞬間にまたぶつかり、連続でHPが減る

### Q10. ぶつかったあとのスネークの動き

- **選択肢**: 止まって方向キーの入力を待つ / すり抜ける / ランダムに方向を変える
- **結論**: ぶつかった演出を少し入れて止まる（例: 1秒）。そのあいだに方向キーが入力されていればその方向に、入力されていなければランダムな方向に動き出す
  - 方向キーが何度か押されたら、最後に押された方向を使う
  - ランダムに選ぶのは、すぐ先が壁でも体でもない方向だけ
  - 無敵時間は、動き出した瞬間から数える
- **理由**
  - 入力を待つ形だと、テンポが途切れ、放置すれば安全な状態が生まれる。自動で動き出せば、スネークは止まれないという基本を保てる
  - 完全にランダムだと、ぶつかった方向や真後ろを引いて、すぐにまたぶつかる

## ハート（回復アイテム）

### Q11. HPの初期値と回復の手段

- **結論**
  - HPの初期値は3
  - 盤面にハートを置く。取るとHPが1回復し、体は伸びない

### Q12. ハートの出し方

- **選択肢**: 一定のポイントを獲得したら / 低確率のランダム / リンゴをk個食べるごと
- **結論**: 累計獲得ポイントが一定量を超えるたびに1個出す。加えて、リンゴと一緒に超低確率で出す
  - 時間ボーナスで一定量を超えたときは、次のステージの開始時に出す
- **理由**: 所持ポイントで数えると、強化を買って減ったあとに同じ基準を何度も超えられてしまう。累計で数えると、「獲得ポイント2倍」を持っているとハートも出やすくなり、リスクを取った見返りになる

### Q13. 盤面に出たハートの扱い

- **結論**
  - 取られるまで盤面に残る。同時に複数個あってもよい
  - HPが満タンのときも出す。満タンのときに取ったら、何も起きない
  - ステージが終わったら、残っていたハートは消える
- **理由**: 満タンのときは取らずに残しておき、ぶつかったあとで取りに行く、という判断が生まれる

### Q14. HPに関する強化の違い

- **結論**: 「HPの上限＋1」は、現在のHPも1増やす。「1回生き返る」は、HPが満タンの状態で復活させる
- **理由**: どちらも「あと1回ぶつかれる」になり、役割が重なるのを避ける。「1回生き返る」が高額である理由にもなる

## ポイントとスコア

### Q15. スコアとポイントを分けるか

- **結論**: 分ける。スコアは到達ステージ数。ポイントは強化を買う通貨の役割だけにする
- **理由**: ポイントをそのまま成績にすると、強化を買うほど成績が下がり、買わないほうが得になる。エンドレスのゲームでは「どこまで進めたか」が一番伝わりやすい

### Q16. ポイントが入るタイミング

- **結論**: リンゴの分は、食べるたびにその場で入る。時間ボーナスは、ステージクリア時に入る

### Q17. 時間ボーナスの計算方法

- **選択肢**: (a) クリアした時点の残り時間から計算する / (b) かかった時間だけから計算する
- **結論**: (a)
- **理由**: (a)なら、制限時間を延ばす強化が時間ボーナスも増やすので、時間切れの心配がないときでも買う理由がある。(b)だと、その効果は時間切れを防ぐことだけになる

### Q18. クリアのモーダルに表示するもの

- **結論**: そのステージで獲得したポイントの内訳（リンゴの分、時間ボーナス、合計）
- **理由**: 「欲張って多く食べた」のか「急いでクリアした」のかの結果が見える

## 強化

### Q19. 強化の買い方

- **結論**: 3つの候補のうち、ポイントが足りる限りいくつでも買える。使わなかったポイントは次のステージに持ち越す
- **理由**: 「使い切るか、次のために貯めるか」という迷いが生まれる

### Q20. スキップボタン

- **結論**: 専用のボタンは作らない。何も買わずに「次のステージへ」を押せば、それがスキップになる

### Q21. リロールの決まり

- **結論**
  - リロールでは、3つすべてを新しくする（買ったあとでも同じ）
  - 3つすべてを買い切ったら、無料で自動リロールする。回数の制限はなし
- **理由**: 買い切ったことへのご褒美になる。残りの強化を全部買ったほうが有料のリロールより安い場面では、リロールボタンを押す理由がなくなるが、これはリロールと強化の値段の関係を遊んで調整すれば済む

### Q22. 同じ強化を重ねて買えるか

- **結論**: 重ねて買え、効果も重なる。強くなりすぎるものには上限を設ける（「HPの上限＋1」と同じ扱い）

### Q23. 「ポイント2倍、長さ2倍」の意味

- **結論**: 1つの強化で、獲得ポイントも長さの伸び方も2倍になる。かなりハイリスク・ハイリターンな強化。数値やバリエーションは調整してよい

### Q24. 「壁に当たってもダメージを受けない」を持って壁にぶつかったとき

- **選択肢**: 止まる（ダメージだけなし） / 通り抜ける
- **結論**: 内側の壁は通り抜ける。外周の壁にぶつかったときは、止まらずにすぐランダムな方向（すぐ先が壁でも体でもない方向）に向きを変える
- **理由**: 止まってしまうと、効果が「HPを守る」ことだけになり、価値が低い。外周は盤面の外に出られないので、通り抜けられない

## 画面

### Q25. ゲームオーバー画面に表示するもの

- **結論**
  - 到達ステージ（スコア）
  - 死因（HPが0になった / 時間切れ）
  - 累計獲得ポイント
  - 残っていたポイント（全然使っていなかった、を見せられる）
  - 最終的な長さ
  - 買った強化の一覧
  - 「もう一度」と「タイトルへ」のボタン
- **理由**: 死因を出すと、なぜ死んだかが分かり、理不尽ではなく「もう1回」になる
