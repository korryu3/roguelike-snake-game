# 壁のパターンを文字で書く（2026-11-06）

**状態: 決定**

壁のパターンをほかの人にも作ってもらい、取り入れられるようにするための決定の記録。

## 背景

壁のパターンは、コードの中に座標の組み合わせとして書いていた。形がひと目で分からず、コードを書かない人には作れなかった。

## 決めたこと

### Q1. パターンの書き方

- **結論**: 文字の絵で書く。`#`が壁、`.`が床。1行が盤面の1行になる

  ```
  ....###########....
  ```

### Q2. パターンをどこに持つか

- **結論**: 調整の数値と一緒に持つ。入力のたびにブラウザに保存され、JSONの書き出しと読み込みでほかの人とやり取りでき、「既定値に戻す」で既定のパターンに戻る

### Q3. パターンの大きさ

- **結論**: どの大きさでもよい。パターンの中央（幅と高さをそれぞれ2で割って切り捨てた位置）を盤面の中央に合わせて置き、盤面からはみ出した分は捨てる。行の長さがそろっていないパターンは受け付けない
- **理由**: 盤面の大きさを調整パネルで変えても、パターンが使えなくならない

### Q4. 中央の空き

- **結論**: パターンの中央のマスとそのまわり（3×3）に壁があるパターンは受け付けない
- **理由**: ステージ開始時と復活のときに、中央のマスに頭を置くため

### Q5. 調整パネルでの編集

- **結論**: 調整パネルに「壁のパターン」の欄を置き、パターンを追加・削除・編集できるようにする
  - パターンごとに、等幅の文字の入力欄を1つ置く
  - 「追加」で、調整パネルで設定している盤面の大きさの、すべて床のパターンを足す。人から受け取ったパターンは、そこに貼り付ける
  - 最後の1つは削除できない
  - 正しくない入力は、ほかの数値と同じく理由を出して反映しない

### Q6. 今回は作らないもの

- 壁で囲まれて入れない区画の検査。パターンを作る人が避ける。問題になったら足す
- 特定のパターンを選んで試す機能。試したいときは、ほかのパターンを一時的に消す

### Q7. 盤面の既定の大きさ

- **結論**: 15×15から19×19にする。既定のパターン3つも、19×19に合わせて外側へ広げて描き直す
