# タイトル・フォント・音（2026-11-06）

**状態: 決定**

チームで決めた、英語のタイトル、フォント、効果音とBGM、ポーズ機能の扱いの記録。

## タイトル

- **結論**: 英語のタイトルを「RoguelikeSnakeGame」から「RLSG」に変える。日本語の「ログスネ」は変えない

## フォント

- **結論**: Google Fontsの「WDXL Lubrifont JP N」を使い、Google Fontsから読み込む
- **理由**: フォントのファイルをHTMLに埋め込むと、日本語のフォントは大きいのでHTMLが重くなる。GitHub Pagesで配るならネットにつながっている前提でよい。つながっていなくても、ふつうのフォントで遊べる
- このフォントの太さは1種類だけなので、太字はブラウザが太く見せる

## 効果音とBGM

どれもクレジット表示は不要で、組み込んでよい素材。

| 場面 | 素材 |
|---|---|
| バッテリー・ハートを取る | 効果音ラボ「カーソル移動9」 |
| 生き返る | 効果音ラボ「決定ボタンを押す43」 |
| ボタン全体 | 効果音ラボ「決定ボタンを押す32」 |
| ステージクリア | 効果音ラボ「プレゼンタイトル表示1」 |
| ゲームオーバー（HPが0・タイムアップで同じ音） | 効果音ラボ「間抜け2」 |
| ゴールが出る | 効果音ラボ「ニュースタイトル表示3」 |
| ダメージを受ける | 効果音ラボ「ロボットを殴る2」 |
| BGM | PeriTune「Rituale Machina」 |

- ダメージの音は、ぶつかったことではなくダメージを受けたことを知らせる。無敵時間中や壁ダメージ無効で防いだときは鳴らさない（2026-11-07に「壁や体にぶつかる」から変えた）
- 素材のファイルはチームが落として、`human-led/src/assets/sounds/`に置く。ビルドでHTMLに埋め込む
- BGMは「ゲーム開始」を押してから流す。ブラウザは、ページを開いただけでは音を鳴らせない
- クリアとゲームオーバーの音が鳴るときは、BGMを止めずに音量を下げる。止めると寂しいため
  - クリアのあとは、モジュールの画面から次のステージに入るときに元の音量に戻す
  - ゲームオーバー画面とタイトルでは、下げたまま流し続け、「もう一度」で元の音量に戻す
- 音を消すボタンを1つ置き、状態はブラウザに保存する。授業中に先生が遊ぶ場面で、音を消したいことがあるため
  - 2026-11-07に、音量のスライダーを持つ設定メニューに置き換えた（[設定メニューと一時停止](./2026-11-07-設定メニューと一時停止.md)）
