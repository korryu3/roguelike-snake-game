# ログスネ（RLSG） コンセプト

チームで決めた[検討事項](./roguelike-snake-検討事項.md)と、[コンセプトの抜けの議論](./discussions/2026-11-05-コンセプトの抜けの議論.md)、[衝突と復活の見直し](./discussions/2026-11-06-衝突と復活の見直し.md)、[壁のパターンを文字で書く](./discussions/2026-11-06-壁のパターンを文字で書く.md)、[タイトル・フォント・音](./discussions/2026-11-06-タイトル・フォント・音.md)、[設定メニューと一時停止](./discussions/2026-11-07-設定メニューと一時停止.md)、[合意のない仕様の見直し](./discussions/2026-11-07-合意のない仕様の見直し.md)の結論をまとめたもの。決めた理由は、議論の記録を参照する。言葉の意味は[用語集](../GLOSSARY.md)、コードがどう動いているかは[内部の挙動のドキュメント](./internals/1-全体像.md)を参照する。

数値はすべて例で、遊んで調整する前提。

## コンセプト

**集めたPPでモジュールを買い、スネークを改造しながら、どこまでステージを進めるかを競う。**

## 前提

- 授業課題のデモ用。遊ぶのは先生
- 対応端末はPCのみ
- 日本語と英語を切り替えられる

## 呼び名

| 日本語 | 英語 | 意味 |
|---|---|---|
| ログスネ | RLSG | ゲームのタイトル |
| スネーク | Snake | プレイヤーが操作する機体 |
| バッテリー | Energy Cell | 盤面に出る、食べると長くなるもの |
| PP（Powerup Point） | PP（Powerup Point） | モジュールを買う通貨 |
| モジュール | Module | ステージの合間に買う強化。機体に取り付ける |
| ハート | Heart | 盤面に出る、取るとHPが1回復するもの。HPの表示にもハートのアイコンを使う |
| スコア | Score | 成績 |

## 基本のルール

- 世界観はロボット・SF
- リアルタイム制（一定間隔で自動で進む）
- ステージがエンドレスに続く。死んだら最初からやり直し（メタ進行なし）
- 敵は出さない。長くなった自分の体が障害になる
- 盤面は19×19マス

## ステージ

- 壁の配置は、事前に作ったパターンの中からランダムに選ぶ。どのパターンも、盤面の中央とそのまわりを空けておく
  - パターンは`#`（壁）と`.`（床）の文字の絵で書き、調整パネルで追加・削除・編集できる
- ステージ開始時は、最初の方向キーを押すまで中央のマスで待つ。待っているあいだは「方向キーで開始」のように表示する。押した瞬間に進み出し、制限時間も減り始める
- バッテリーは常に盤面に1個。食べると、次の1個がランダムな空きマスに出る
- バッテリー、ゴール、ハートが出るのは、壁、体、ほかのもの、中央のマスのどれとも重ならない空きマス
  - 空きマスがなければ、頭を除く体のマスの上に出す。ものを取るのは頭が入ったときだけなので、体が離れてから取る。体の上のものは、体より手前に見える
  - 頭が入ったマスのものは、体をすり抜けて入ったときも取る
- バッテリーをn個食べると、ランダムな位置にゴールが現れる。ゴールに入るとクリアになる
  - ゴールに入るまでは、バッテリーを追加で食べ続けられる。食べるほどPPは増えるが、体が長くなり、タイムボーナスも減る
- nは、ふつうに遊んで30〜60秒ほどでゴールが出る量にする
- 制限時間は、最大で1分ほど。ゴールが出たあとも減り続け、タイムアップになったらゲームオーバー
- 進行バーは、食べたバッテリーの数（n個中いくつか）を表す。ゴールが出たら、満タンのまま光るなどして知らせる

## 長さ

- バッテリーを食べると長くなる
- ラン開始時の長さは3
- 長さはステージをまたいで持ち越す
- ステージ開始時は、盤面の中央のマスに頭だけが現れる。進むにつれて、中央のマスから体が1マスずつ出てきて、元の長さまで伸びる
  - 盤面の中央は、周りより暗くする（穴は開けない）
- 難易度を上げる仕組みは、長さの持ち越しだけにする。nや制限時間をステージごとに変えるかは、遊んでから決める

## HPとダメージ

- HPの初期値は3。ハートで表す
- 壁や自分の体にぶつかると、HPが1減る。体は長くも短くもならない
- 壁にぶつかったあとの動き
  - 点滅しながら少し止まる（例: 1秒）。止まる長さは、遊んで調整する。止まっているあいだも、制限時間は減る
  - 止まっているあいだに方向キーが入力されていればその方向に、入力されていなければランダムな方向に動き出す。何度か押されたら、最後に押された方向を使う。真後ろ（首の方向）は捨てる
  - ランダムに選ぶ順は、すぐ先が壁でも体でもない方向 → すぐ先が体の方向（真後ろ以外） → 真後ろ → 4方向から完全にランダム
  - 動き出した瞬間から、短い無敵時間が付く
  - 無敵時間中に壁にぶつかったら、ダメージなしで、止まらずにその場でランダムに向きを変える（向きの選び方は、ぶつかったあとに動き出すときと同じ）
- 自分の体にぶつかったあとの動き
  - 止まらずに、体の上をすり抜けて進む。体で頭を囲んでしまっても抜け出せる
  - ぶつかった瞬間から無敵時間が付くので、1回すり抜けるあいだに減るHPは1
  - 無敵時間中に体へ入ったら、ダメージなしで、向きを変えずにすり抜ける
- 真後ろへの入力は無視する

### ハート（回復アイテム）

- 取るとHPが1回復する。取っても体は伸びない
- 累計獲得PPが一定量を超えるたびに1個出る。一度に複数の基準を超えたら、超えた数だけ出る。加えて、バッテリーと一緒に超低確率で出る
- 取られるまで盤面に残る。同時に複数個あってもよい
- HPが満タンのときも出す。満タンのときに取ったら、何も起きない
- ステージが終わったら、残っていたハートは消える

### HPが0になったとき

- モーダルを出し、持っている「1回復活」系のモジュールと、「諦める」ボタンを並べる。生き返るモジュールを持っていなければ、モーダルを出さずにゲームオーバー
- プレイヤーは、どのモジュールを使って生き返るかを選ぶ。「諦める」を選んだら、ゲームオーバー
- モーダルを出しているあいだは、制限時間を止める
- 生き返ったら、ステージ開始時と同じく、中央のマスに頭だけが現れ、そこから元の長さまで伸びる。長さ、壁、バッテリー、ゴール、ハート、残り時間はそのまま
- 生き返ったあとは「方向キーで開始」を出し、方向キーを押すまで待つ。待っているあいだは制限時間を止める。無敵時間は付けない

## PPとスコア

- PP
  - モジュールを買う通貨
  - バッテリーを食べたときだけ、その場で増える
  - 使わなかったPPは、次のステージに持ち越す
- スコア
  - 成績。バッテリーの数×係数 ＋ タイムボーナスで計算する
  - タイムボーナスは、ゴールに入った時点の残り時間が多いほど多い。制限時間を延ばすモジュールは、タイムボーナスも増やす
- 到達ステージ数とスコアは、別々に扱う

## モジュール

- 買えるのは、ステージをクリアしたときだけ。ステージ中のレベルアップはない
- 10種類ほどの中から、ランダムに3つの候補を出す
- 3つのうち、PPが足りる限りいくつでも買える。何も買わずに「次のステージへ」を押してもよい
- PPを払うと、3つすべてを引き直せる（リロール）。買ったあとでも、3つすべてが新しくなる
- 3つすべてを買い切ったら、無料で自動リロールする。回数の制限はなし
- 同じモジュールを重ねて買え、効果も重なる。強くなりすぎるものには上限を設ける
- 良いモジュールほど高い。メリットとデメリットの両方があるモジュールも入れる

### 必ず作るモジュール

| モジュール | 英語 | 効果 |
|---|---|---|
| PP・伸び2倍 | Double PP & Growth | バッテリー1個で得るPPが2個分になり、体の伸びも2マスになる。スコアのバッテリーの分は2倍にしない |
| 1回復活（完全回復） | Revive (Full) | HPが0になったとき、HPが満タンの状態で生き返る。高額 |
| 1回復活（一部回復） | Revive (Partial) | HPが0になったとき生き返るが、HPは1で復活する。少し安い |
| 制限時間延長（永続） | Time Extension (Permanent) | 制限時間を5秒延ばす。恒久的 |
| 制限時間延長（次のステージ） | Time Extension (Next Stage) | 次のステージだけ、制限時間を延ばす |
| 壁ダメージ無効 | Wall Damage Immunity | 壁にぶつかってもダメージを受けない。ぶつかったら1回分を消費する（開始数秒だけ効くなどの種類は、できたら作る）。ぶつかったときの動きは、ダメージを受けたときと同じ。自分の体にぶつかったら、ダメージを受ける |
| HPの上限＋1 | Max HP +1 | HPの上限が1増え、現在のHPも1増える。上がり幅に上限を設ける |
| PP2倍のバッテリー | Double-PP Energy Cell | n%の確率で、PPが2倍のバッテリーが出る。スコアのバッテリーの分は2倍にしない |

### できたら作るモジュール

- ステージクリアに必要なバッテリーの数が増える。PPは増えるが、クリアが難しくなる
- 体の一部を切り落とす（例: 次のステージで、自分の体にぶつかった位置から先を切断する。使い切り）
- n%の確率で、モジュールの候補が4つに増える
- 移動速度1.5倍
- 移動速度が落ちるが、PPの倍率が少し上がる

## 画面

### 画面遷移

タイトル → ステージ → クリアのモーダル →（ボタンを押す）→ モジュールのモーダル → 「次のステージへ」 → 次のステージ → …（エンドレス）

HPが0になったら、生き返るモーダルを出す。ゲームオーバーになったら、ゲームオーバー画面に移る。

### タイトル

- 「ゲーム開始」ボタン
- 設定ボタン（「⚙ 設定 / Settings」と両方の言葉で出す）。日本語と英語の切り替えは、設定メニューの中で行う

### ステージ中

- 進行バー
- スネークを操作する盤面
- これまでに買ったモジュール
  - 使い切るモジュール（1回復活、壁ダメージ無効、制限時間延長（次のステージ））は、残りの数を出す。使い切っても一覧から消さず、薄暗くして残す
- HP（ハート）
- ステージ番号
- 所持PP
- タイマー
- 操作方法（右下などに、WASDで操作することをUIとして書く）
- 設定ボタン（時間制限の上。一時停止、音量の調整、言語の切り替え。[設定メニューと一時停止](./discussions/2026-11-07-設定メニューと一時停止.md)を参照）
- 別のタブに移ったら一時停止にし、戻ったら方向キーで再開する
- 盤面とHUDは、画面の高さに収まるよう縮めて表示する
- Tキーで、数値の調整パネルを開ける（公開版でも開ける）。開くと一時停止になる

### クリアのモーダル

- クリアしたステージの番号
- 獲得したPP
- 獲得したスコア（バッテリーの分、タイムボーナスの分）
- クリアにかかった時間

### ゲームオーバー画面

- 到達ステージ
- スコア
- 死因（HPが0になった / タイムアップ）
- 累計獲得PP
- 残っていたPP
- 最終的な長さ
- 買ったモジュールの一覧
- 「もう一度」と「タイトルへ」のボタン

## 最初の完成ライン

これができたら、「できたら作る」モジュールを足していく。

- 画面遷移の一式（タイトル → ステージ → クリア → モジュール → ゲームオーバー）
- 必ず作るモジュール8種
- 壁のパターン3種類
- ハート
- 日本語と英語の切り替え

## 作るときの方針

- 説明なしで遊べるようにする。最初の画面で操作方法が分かること
- 見た目のインパクトより、ルール同士がかみ合っていることを優先する
- コンセプトの説明は発表スライドに任せる。ゲームは説明に頼らず、作品として完成させる

## 実装しながら決めること

- 移動速度や曲がるときの反応などの数値
- エフェクトや画面の揺れの強さ
- 難易度曲線とバランスの数値（モジュールとリロールの値段、ハートが出る基準など）
- 死んでから再挑戦するまでの手間
- 死因の分かりやすさ
- チュートリアル
- 中断したプレイの再開
- モジュールの説明の見せ方
- アクセシビリティ（色だけに頼らない、矢印キーとWASD、速度を遅くするオプション）
